Добавить стримера в streamers.json

Страница на GitHub Pages статична и не может сама писать в репозиторий — заполни форму, скопируй получившийся JSON и вставь его в файл streamers.json в репозитории (или скачай файл и загрузи вместо старого). После коммита workflow подхватит изменения автоматически (см. триггер push: paths: streamers.json) или запусти его вручную во вкладке Actions.

Как это устроено

Запросы к Raider.IO выполняются не из браузера, а на сервере GitHub Actions по расписанию (workflow .github/workflows/update-data.yml) — поэтому проблема CORS не возникает вообще, никакие прокси не нужны. Скрипт scripts/fetch_data.py читает streamers.json, запрашивает Raider.IO и пишет результат в data.json, который эта страница просто подгружает как обычный статический файл со своего же домена.

Season в запросе не указывается — Raider.IO по умолчанию отдаёт данные текущего сезона, так что при выходе Midnight Season 2 и далее менять ничего не нужно.

Первый запуск

  1. Убедись, что в настройках репозитория (Settings → Actions → General → Workflow permissions) включено «Read and write permissions» — иначе workflow не сможет закоммитить data.json.
  2. Отредактируй streamers.json (через форму выше или вручную) и запушь.
  3. Зайди во вкладку Actions → «Обновить данные M+» → Run workflow, чтобы не ждать первый автозапуск по расписанию.
  4. Через минуту-две обнови страницу — данные подтянутся из свежего data.json.
