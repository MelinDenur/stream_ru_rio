Как найти реалм и имя персонажа стримера

Если в описании канала стоит расширение Raider.IO (WoW M+) или указан battletag — открой ссылку из панели ниже плеера, она обычно выглядит как raider.io/characters/eu/realm/CharacterName: возьми регион, реалм и имя оттуда. Если такой ссылки нет — многие стримеры держат чат-команду вроде !rio или !армори, либо публикуют battletag в панелях «О канале» / Discord. Реалм нужно вводить в формате из URL Raider.IO — например «Howling Fjord» → howling-fjord.

Страница всегда запрашивает данные текущего сезона (без указания season в API) — поэтому при выходе второго и последующих сезонов Midnight ничего менять не нужно, таблица сама покажет актуальные ключи и Score.

Про CORS-прокси

У Raider.IO API нет CORS-заголовков для сторонних доменов, поэтому запросы идут через публичный прокси allorigins.win. Он бесплатный, но иногда бывает медленным или временно недоступным — если видишь ошибку «прокси недоступен», просто нажми «Обновить все данные» ещё раз через несколько секунд.

Для надёжной работы (например, если планируешь показывать страницу зрителям постоянно) лучше поднять свой прокси на Cloudflare Workers — это бесплатно и занимает пять минут:
  1. Зайди на workers.cloudflare.com, создай аккаунт и нажми «Create Worker».
  2. Вставь этот код вместо шаблонного:
    export default { async fetch(request) { const url = new URL(request.url); const target = url.searchParams.get("url"); const resp = await fetch(target); const body = await resp.text(); return new Response(body, { status: resp.status, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" } }); } }
  3. Нажми Deploy — получишь адрес вида https://имя.твой-ник.workers.dev.
  4. В коде страницы замени CORS_PROXY_PREFIX на https://имя.твой-ник.workers.dev/?url=.
